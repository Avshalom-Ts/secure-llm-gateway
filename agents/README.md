# Agent Roles

This folder contains optional instructions for specialized coding-agent roles. Use these files only when work is split between agents or when a role needs project-specific constraints.

- `orchestrator/` — plans work, coordinates handoffs, and checks completion.
- `frontend/` — owns user-interface implementation and client-side tests.
- `backend/` — owns services, APIs, persistence, and server-side tests.
- `qa/` — validates requirements, regression coverage, and release readiness.

Customize, add, or remove roles to fit the project. Shared instructions belong in `AGENTS.md`.
