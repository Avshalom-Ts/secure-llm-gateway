# Project Starter

This repository is a generic starting point for new software projects.

## Before You Start

1. Replace the placeholders in `.doc/product-definition.md`.
2. Update `.doc/architecture.md` when the technical approach is chosen.
3. Add shared vocabulary to `.doc/glossary.md`.
4. Keep only the `.rule/` guidance that fits the project and technology stack.
5. Record planned work in `.plan/` when a durable implementation plan is useful.

## Included Structure

- `.doc/` — product, architecture, and terminology templates
- `docs/` — human-facing guides, references, and operating documentation
- `.plan/` — implementation plans and backlog
- `.rule/` — adjustable engineering standards
- `AGENTS.md` — instructions for coding assistants and collaborators
- `agents/` — optional role-specific instructions for multi-agent work

Add application code, tooling, and project-specific documentation as the project takes shape.
