# Project Documentation

Use this folder for documentation intended primarily for people working on or using this project.

Suggested documents:

- `getting-started.md` — setup and local development instructions
- `user-guide.md` — how to use the product
- `api.md` — public API or integration documentation
- `decisions/` — architecture decision records
- `runbook.md` — operational and support procedures

Keep technical source-of-truth templates in `.doc/`, and place reader-friendly explanations, guides, and examples here.
